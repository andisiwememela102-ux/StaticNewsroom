# The Daily Brief - Static Newsroom

A responsive newsroom landing page built with plain HTML and CSS for the static website deployment practical.

## Live site

https://andisiwememela102-ux.github.io/StaticNewsroom/

## Project files

- `index.html` - page content and metadata
- `styles.css` - responsive layout and visual styles
- `static_page.png` - screenshot of the deployed page with its URL visible
- `static_url.txt` - deployed URL required by the practical

The story copy is sample editorial content, not reporting about current events.

## Run locally

Open `index.html` in a browser. No build step or server is required.

## Deploy

GitHub Pages publishes the repository root from the `main` branch.
